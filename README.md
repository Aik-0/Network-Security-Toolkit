# All-In-One Security Suite (AOSS)

A lightweight Python security toolkit for network scanning, traffic monitoring, and threat detection.

### Features
- **Port Scanner:** Detects open TCP ports.
- **Packet Sniffer:** Captures TCP/UDP traffic using Scapy.
- **Log Analyzer:** Detects suspicious activity and brute-force attacks.

### Installation
```bash
pip install scapy
```

### Run
```bash
python security_suite.py
```
